Bienvenida

Este portal reúne la información esencial del curso: plan de trabajo, recursos, evaluaciones y canales de comunicación. Mantén este sitio como referencia durante el cuatrimestre para verificar fechas, entregas y avisos.

Avisos recientes

  • Semana 1: Diagnóstico inicial y repaso de bases de HTML.
  • Semana 2: Laboratorio de estructura de sitio (múltiples páginas).
  • Semana 3: Aplicación progresiva de reglas CSS (Parte 2).

Tema de la semana

Construcción de un sitio web básico: navegación, páginas internas y organización de contenido para que luego CSS pueda mejorar la apariencia sin cambiar la estructura.
