Objetivo general

Desarrollar un sitio web básico con múltiples páginas, aplicando buenas prácticas de estructura HTML y estilos CSS progresivos para mejorar la presentación.

Cronograma sugerido (4 semanas)

Semana Temas Producto
1 Estructura HTML, rutas y navegación Mini-sitio con 5 páginas
2 Contenido: listas, tablas, enlaces, secciones Contenido completo por página
3 CSS: tipografía, layout, navegación, componentes Estilos base + mejoras visuales
4 Mejoras: consistencia, legibilidad, detalles Versión final + revisión

Reglas de trabajo

  1. Organizar los archivos por nombre y estructura consistente.
  2. Evitar duplicar contenido: reutilizar ideas, pero adaptar el texto.
  3. Probar navegación en el navegador en cada avance.
